# 患者向纯图片可视化报告

本能力只在用户明确要求纯图片报告、图片套图或图像解释时执行。它使用与 H5 完全相同的
已校验 `presentation_projection`，由 Image 2 把最终患者文字、专业判断和视觉解释一体
生成可逐张阅读、保存和分享的图片，不重新进行医学推理。

当前生产链以 Codex 提供的 Image 2 图像生成、局部编辑和原图查看能力为运行基准，尚未
在其他 Agent 宿主上做兼容测试。宿主缺少这些能力时不执行纯图片生产，也不改为要求独立
模型 API；已经提交的文字结果和不依赖生成图的 H5 能力不受影响。

## 1. 输入与边界

只读取当次已校验纯净版并保存其 `schema_version`、SHA-256、`run_id` 和 `result_id`。
不得读取完整 analysis 补内容，不生成另一份患者理解任务或关系模型。允许把纯净版标题、
患者解释和模块文字压缩、拆分或标签化，以适应画幅和图文融合；不得改变医学含义与边界。

套图编排只做三件事：

1. 按信息量决定页数；
2. 选择每页引用的纯净版字段；
3. 决定同一段内容在画面中的视觉强调。

页面可以合并语义连续的字段或拆分过长模块，但显示文字必须能逐项追溯到纯净版。旧套图、
旧提示词和样例病例不得成为新报告的内容或主视觉输入。

## 2. 套图计划与患者标题

先形成 `image_suite_plan`：

```text
schema_version              固定 1.0
projection                  schema、SHA-256、run_id、result_id
visual_system               本案 R0 融合、配色、状态编码和禁区
pages[]
  index                     从 1 连续递增
  file                      PNG 文件名
  type                      本页图像类型
  projection_fields[]       本页理解所需的纯净版字段路径
  display_text[]            {source_field, text, mode}
  emphasis                  首要、次要与边界信息的视觉权重
```

`display_text` 是本页唯一可见文字白名单，顺序就是阅读层级。第一项必须是患者向页面标题：

- 使用“患者要理解的对象＋本页结论／范围”的陈述式短标题，不使用问句；
- 不直接把 R0／R1 的专业章节名当页面标题；专业标题与必要原句可在正文保留；
- 不出现“R0”“R1”“关系模型”“条件性四轴”等内部或研究型命名，除非用户明确要求；
- 标题可用 `label` 从所引纯净版字段形成患者向短句，不需要逐字复制专业标题。

三种模式的含义：

- `exact`：身份、方剂原文、药味顺序、剂量、炮制煎服、专业直接引文等逐字守恒内容；
- `condensed`：纯净版已决定的语义经过压缩或拆分，条件、未知和状态不得消失；
- `label`：标题、节点、图注、页码和品牌小署名等媒介标签。

不得加入 `patient_task`、新医学摘要、预设医学结论或固定主物象。页数不固定，只覆盖实际
存在的内容；无方、无观察、无 R1 或无五行卦象时省略对应页面。

## 3. 图片类型与视觉载体

同一套图必须使用不同但相关的内容载体。下列类型是选择空间，不是固定页序：

- 总览：编辑型主视觉与核心关系场；
- R0／R1：人体轮廓、经络式流向、阴阳张力、上下内外、左右升降、开合与空间流场；
- 证机／治法：人体气机、作用路径、真实可辨的机制场景或连续分镜；
- 方药协同：植物、饮片、炮制质感、制备场景与药群关系；
- 完整组成／事实：高密度事实图与称量、药包、炮制、后下或器具融合；
- 观察／复察：人物状态、时间分镜、正反路径和前后对照；
- 边界：门槛、退出路径、复核场景和必要状态矩阵；
- 经典：原文意象、概念关系和跨书关系。

让 Image 2 在这些载体中根据当前页文字自行选择，不在生成前增加“比喻审核”步骤，也不
锁死具体物件。通用选择约束如下：

- 显著图形必须帮助理解正文，不能生成无法解释的蜂窝、孔洞、风景或大型器物；
- 气机、升降、开合和经络优先使用人体轮廓、经络或身体流向；
- 只有 R1 的脏腑关系本身需要空间解释时才使用选择性脏腑，不以完整解剖营造专业感；
- 方药优先使用植物、饮片、炮制和制备场景，待核药名不得生成确定物种身份；
- 观察和复察优先使用人物状态、分镜、时间或正反路径，不画无数据疗效曲线；
- 除纯事实台账外，页面不能只由文字框、圆点、箭头和状态线组成；
- 绢纸、玉青、竹简、金属等只塑造气质，不充当默认主物象。

R0 影响阴阳、空间、动势、五行和审美；R1 决定哪些人体、经络或脏腑含义可以进入画面。
两者可以在同页融合，不按角色机械切页。

## 4. 提示词编译

固定品牌母体来自
[`../assets/pure-image-report/brand-visual-profile.json`](../assets/pure-image-report/brand-visual-profile.json)。
它只固定编辑气质、基础材质、字体、状态语义和禁区，不固定病例主色、页面物象或 R0 动势。

计划完成后运行：

```bash
python3 -B scripts/prepare_pure_image_suite.py \
  --plan /absolute/path/to/working/image-suite-plan.json \
  --projection /absolute/path/to/presentation/presentation-projection.json \
  --output-dir /absolute/path/to/working/prompts
```

脚本必须先校验 projection 绑定、字段路径、页序、文件名和 `exact` 文案，然后逐页生成：

- 当前页必要的纯净版上下文，仅供模型理解；
- 唯一可见文字白名单；
- 从白名单提取的数字／剂量白名单；
- 固定品牌母体、本案 R0 视觉融合、状态语义和禁区；
- `generation-batches.json`，默认每批三张。

同一输出目录已存在时必须显式使用 `--force`，避免意外覆盖。编译器不选择医学结论或视觉
比喻，只把宿主完成的计划变成确定性提示词。

## 5. Image 2 一体生产

每页由 Image 2 一次完成主视觉、图形解释、中文文字、版式、材质、页码和品牌小署名。
不要拆成无文字视觉层与后置文字层，也不要用 SVG、网页卡片或确定性关系框替代纯图创作。

生产按 `generation-batches.json` 执行：

1. 品牌母体已有成功基线时不再单独制作一页试稿；
2. 同批最多并发三张，批次之间顺序推进；四张并发没有稳定速度收益，不作为默认值；
3. 每张图只读取自己的提示词，不引用上一内容页来复制主物象；
4. 原始尺寸直接生成，不先做低清草稿；低清试稿不能可靠验证中文和高密度信息；
5. 完成一个批次后即可检查原图，同时启动下一批，避免全部生成后集中返工。

已有品牌级视觉参考可以复用；病例专属图片、人物、药群、场景和构图不能成为下一病例模板。

## 6. 原图复核与一次纠错

检查不是独立生产阶段，只负责决定交付或立即纠错。必须先查看原始分辨率，不能凭缩略图、
压缩预览或 OCR 猜测错字；OCR 只能提示可疑位置，不能作为重生依据。

按以下顺序处理：

1. 主物象无关、人体载体错误、视觉退化为线框，或医学内容／状态／病位／药材身份／疗效
   越界：整页更换视觉路线重新生成；
2. 核心标题、药名、剂量、顺序、炮制、身份或成立条件错误：整页重新生成，不能靠遮盖掩盖；
3. 孤立且必要的局部中文错误：只做一次 Image 2 局部编辑；
4. 非必要的自动印章、书页字、器具标签、英文或页码：直接要求删除，不为装饰文字循环修补；
5. 一次局部编辑仍失败：删除非必要文字，或按原提示整页重生，不进入多轮编辑循环。

把同批发现的纠错页一次并发处理，仍以三张为上限。最终目录只接收已经看过原图并通过的
版本，中间稿留在 `working/`。

## 7. 最终清单与验收

最终目录只保留正式 PNG 和 `image-suite-manifest.json`。manifest 至少记录页码、文件名、
引用纯净版字段、纯净版 schema／SHA-256／run／result、尺寸、字节数和文件 SHA-256。

运行：

```bash
python3 -B scripts/validate_pure_image_manifest.py \
  --manifest /absolute/path/to/final/image-suite-manifest.json \
  --projection /absolute/path/to/presentation/presentation-projection.json \
  --final-dir /absolute/path/to/final
```

交付前确认：

- H5 与纯图片读取同一纯净版；表层文案可以不同，但没有第二套医学内容；
- 页面标题是患者语言，专业判断保留在正文层而不抢占标题；
- 所有事实、条件、未知、正反观察和审计边界保持原身份；
- R0 影响空间、动势和审美，R1 才允许人体医学落点；
- 删除正文后仍能辨认页面在解释身体、对象、方向、协同、时序或边界；
- 视觉丰富度来自内容相关的人体、经络、植物、场景和关系，不是装饰性大图；
- 最终清单只指向正式成品，目录没有样式板、初稿或修订稿。
